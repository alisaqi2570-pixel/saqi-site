سایت رایگان Saqi (دری)
========================

فایل اصلی سایت: index.html

پیش از انتشار:
1) فایل index.html را با یک ویرایشگر متن باز کنید.
2) پایین فایل، در بخش تنظیمات جاوااسکریپت، مقدار WHATSAPP_NUMBER را عوض کنید.
   شماره را با کد کشور و فقط ارقام بنویسید، بدون + یا فاصله.
   نمونه افغانستان: 93701234567
3) نام محصولات، توضیحات، قیمت‌ها و آدرس نمونه را تغییر دهید.
4) لینک عکس‌ها در بخش img را می‌توانید با لینک عکس‌های خود جایگزین کنید.

انتشار رایگان با GitHub Pages:
1) در مرورگر موبایل به https://github.com بروید و حساب رایگان بسازید یا وارد شوید.
2) از منوی + گزینه New repository را انتخاب کنید.
3) نام مخزن را saqi-site بگذارید و Public را انتخاب کنید؛ سپس Create repository را بزنید.
4) Add file > Upload files را انتخاب کنید و فایل index.html را آپلود کنید.
5) پایین صفحه Commit changes را بزنید.
6) وارد Settings > Pages شوید.
7) در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
8) Branch را روی main و پوشه را روی /(root) قرار دهید و Save را بزنید.
9) کمی صبر کنید؛ آدرس سایت معمولاً چنین می‌شود:
   https://YOUR-USERNAME.github.io/saqi-site/
   YOUR-USERNAME را با نام کاربری GitHub خود عوض کنید.

یادآوری:
- انتشار رایگان است و دامنه اختصاصی .com شامل آن نیست.
- برای کارکردن دکمه واتساپ، شماره واقعی خود را در WHATSAPP_NUMBER وارد کنید.
- عکس‌های نمونه از لینک‌های آنلاین بارگذاری می‌شوند؛ برای ماندگاری بیشتر می‌توانید از عکس‌های خود استفاده کنید.
- این قالب سفارش را از طریق واتساپ می‌فرستد؛ سیستم پرداخت آنلاین یا مدیریت موجودی ندارد.
